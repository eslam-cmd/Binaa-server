# Admin Backend - إسلام هداية

باكند لإدارة موقع إسلام هداية مع نظام مصادقة آمن.

## الميزات

- 🔐 مصادقة بخطوتين (OTP عبر الإيميل)
- 🍪 جلسات آمنة في Cookies
- 🛡️ حماية ضد CSRF, XSS, Brute Force
- 📊 إدارة المقالات (CRUD)
- 📋 إدارة الطلبات (قبول/رفض)
- ⚙️ إدارة الخدمات
- 📧 إشعارات إيميل
- 📱 إشعارات Telegram
- 📝 سجل النشاطات

## المتطلبات

- Node.js 18+
- PostgreSQL (Neon)
- Gmail (للإيميلات)

## التثبيت

```bash
# تثبيت الحزم
npm install

# إنشاء ملف البيئة
cp .env.example .env

# تحديث بيانات البيئة
nano .env

# إضافة البيانات المبدئية
npm run db:seed

# تشغيل في وضع التطوير
npm run dev
```
